# Services — Microservicios Auxiliares (FastAPI)

Microservicios complementarios ligeros construidos con **Python 3.11+ / FastAPI**. Orientados a tareas específicas asíncronas, procesamiento de datos pesados, reportería analítica y futura integración con IA/ML.

## Servicios Previstos

```
services/
├── analytics/             # Generación de reportes de retención, flujo de caja y proyecciones
├── notifications/         # Worker asíncrono para WhatsApp, correos transaccionales y recordatorios
└── data-pipeline/         # Procesamiento por lotes y sincronización
```

## Requisitos Previos

- Python 3.11+
- Poetry o `venv` + pip
