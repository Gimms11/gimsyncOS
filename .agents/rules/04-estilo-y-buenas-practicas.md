# Regla 04: Estilo, Buenas Prácticas y Calidad

Directrices de ejecución para el agente Antigravity en este proyecto:

1. **Edición Quirúrgica:**
   - Modificar únicamente las líneas indispensables para cumplir la tarea.
   - Respetar el formato y convenciones del código preexistente.

2. **Commits Convencionales:**
   - Estándar: `tipo(alcance): descripción` en minúsculas y modo imperativo.
   - Tipos: `feat`, `fix`, `docs`, `refactor`, `chore`, `test`.

3. **No Asumir Parámetros Comerciales:**
   - Si no hay certeza sobre precios de membresías, comisiones de pago o penalizaciones, consultar al usuario antes de escribir especificaciones.

4. **Enlaces Clickeables:**
   - Todo archivo modificado o generado debe referenciarse con enlace markdown (`[nombre](file:///ruta)`).
