# Mobile — App Móvil para Clientes y Check-in (React Native + Expo)

Aplicación móvil multiplataforma (Android & iOS) desarrollada con **React Native + Expo** contemplada para la **Fase 2** del proyecto.

## Alcance Previsto (Fase 2)

- Credencial digital y carnet virtual del alumno.
- Acceso al gimnasio mediante código QR dinámico (check-in sin contacto).
- Consulta de vigencia de membresía, historial de pagos y congelamientos.
- Notificaciones push de vencimientos, renovaciones y promociones.
- Reserva de clases grupales y disciplinas (baile, spinning, funcional).

## Requisitos Previos

- Node.js 20+
- Expo CLI
- Expo Go (en dispositivo físico o emulador Android/iOS)
