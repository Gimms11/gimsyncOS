- Solo la **última versión** es la vigente para desarrollo.
- Versiones anteriores se conservan como referencia histórica.
- Cambios menores se reflejan en el changelog del propio documento.
- Cambios mayores (nuevo módulo, redefinición de alcance) generan nueva versión.
